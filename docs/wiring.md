# 硬件连接说明

> 主控：**ESP32-S3**（本项目实测板：Adafruit ESP32-S3，4MB Flash）
> 执行器：SG90 舵机（9g 微型舵机）+ 3D 打印/纸板手指支架
> 目标：用舵机带动的"手指"去按制冰机的电源/开关按钮

---

## 1. 接线总表

| SG90 舵机线 | 颜色 | 接到 | 说明 |
|---|---|---|---|
| 信号 Signal | 橙（或黄） | **ESP32 GPIO4** | PWM 信号，50Hz |
| 电源 VCC | 红 | **外部 5V 电源 +** | ⚠️ 不要接 3.3V |
| 地 GND | 棕（或黑） | **外部 5V 电源 −** 同时接 **ESP32 GND** | 必须共地 |

| 其他 | 接到 | 说明 |
|---|---|---|
| 外部 5V 电源 | 5V 2A 以上适配器 / 充电宝 | 与 ESP32 共地即可，不必共电源 |
| 可选：手动按键 | GPIO0 与 GND 之间 | 板上 BOOT 键是 GPIO0（低电平有效），可直接用 |
| ESP32 供电 | USB 口（USB-C） | 或 5V 引脚，但建议独立 USB 供电 |

### 接线示意

```
               外部 5V 电源 (5V/2A)
                 +          -
                 |          |
                 |          +----------------------+
                 |                                 |
        (红线)   |                                 |  (棕线)
           +-----+-----+                     +-----+-----+
           |   SG90    |                     |           |
           |  舵机     |                     |           |
           +-----+-----+                     |           |
                 |  (橙线 信号)               |           |
                 |                           |           |
                 +--> GPIO4                  |           |
                                             |           |
    USB 5V ---> [ESP32-S3] ------------------+           |
                       GND -------------------------------+
                       (ESP32 的 GND 必须和舵机电源负极相连)
```

> 关键点只有一句：**舵机电源用外部 5V，ESP32 和舵机必须共地。**
> 如果暂时用开发板 5V 引脚给舵机供电，单只 SG90 空载一般能转，但一受力就容易
> 触发 ESP32 复位（电压跌落），所以正式使用请务必外接 5V。

建议在舵机电源正负极之间并联一个 **470µF ~ 1000µF 电解电容**，抑制启动瞬间的电压跌落。

---

## 2. 为什么用 GPIO4

- GPIO4 在 ESP32-S3 上是普通 IO，复位时没有特殊电平要求，不影响启动；
- 避开了这些"坑"引脚：
  - `GPIO2 / 8 / 9`：启动 strapping（GPIO9 是板上 BOOT 键）
  - `GPIO18 / 19`：USB D− / D+
  - `GPIO12~17`：接 Flash
- 想换引脚：改 `firmware/src/main.cpp` 里的 `#define PIN_SERVO 4` 即可，建议 4/5/6/7/15/16/17。

## 3. 手指机械结构（怎么按到按钮）

SG90 的转角范围是 0~180°。本项目用两个角度：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `restAngle` 抬起角度 | 25° | 手指离开按钮的待机位置 |
| `pressAngle` 压下角度 | 75° | 手指把按钮按到底的位置 |
| `holdMs` 按住时长 | 450ms | 按住多久再松开 |

安装步骤：

1. 把舵机固定在制冰机按钮旁边（3D 打印支架 / 热熔胶 / 扎带 / 双面胶 + 硬纸板都行）；
2. 舵机摆臂（或粘在摆臂上的"手指"）要能覆盖按钮上方 3~8mm；
3. 上电后用网页里的「舵机校准」调节：
   - 先调 **抬起角度**，让手指刚好不碰按钮；
   - 再调 **压下角度**，让按钮被按到底（听到/感觉到"咔"）；
   - 用「试按一次」验证，按不动就加大压下角度，按太狠（顶死）就减小；
4. 保存即可，参数会写进 Flash，断电不丢。

> 舵机不要长时间堵转顶住按钮，`holdMs` 建议 ≤ 800ms。

---

## 4. 上电顺序 & 指示灯

1. 先接好线，确认舵机 5V 与 ESP32 GND 相连；
2. 插上 ESP32 USB，舵机会先摆到"抬起角度"；
3. 首次上电没有 WiFi 信息 → 自动开热点 `IceFingerBot`（密码 `icebot1234`）；
4. 手机连该热点 → 打开 `http://192.168.4.1` → 配置家里 WiFi → 设备重启；
5. 之后在路由器里能看到设备 IP，也可以直接访问 `http://icebot.local`。

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 舵机不动，网页能打开 | 信号线没接 GPIO4，或舵机电源没接 / 没共地 |
| 按一下 ESP32 就重启 | 舵机抢电，换外部 5V 电源 + 加电容 |
| 舵机抖 / 嗡嗡响 | 角度到极限顶死了，把 `pressAngle` 调小一点 |
| 网页打不开 | 手机连的是家里的 WiFi，应该连 `IceFingerBot` 热点；或设备没上电 |
| **手机搜不到 `IceFingerBot` 热点** | 板子射频/天线问题：C3 小板常见（U.FL 没接天线）。换 S3 或给板子接天线；用 `firmware/test/ap_probe` 固件可确认 |
| 定时不准 | 设备没联网就没法 NTP 对时，可在网页点「用浏览器时间对时」 |
