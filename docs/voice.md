# 接入小米音箱（小爱同学）

> 现状：固件已支持（巴法云 MQTT），**但还没在真机上验证**——需要你先注册巴法云拿到私钥。

## 1. 为什么走巴法云

| 路子 | 能不能做 | 说明 |
|---|---|---|
| 小米 IoT 开发者平台（正式接入米家） | ❌ 个人做不了 | 需要企业资质 + 产品认证 |
| 小爱开放平台自定义技能 | ⚠️ 门槛高 | 需要开发者账号审核，回调要公网 HTTPS |
| **巴法云「云云对接」** | ✅ 可行 | 巴法云主题同步到米家「其他平台设备」，小爱直接控制 |
| 天猫精灵 / 小度 | ✅ 类似 | 巴法云也支持，但天猫精灵那条已下线 |

原理：巴法云主题名**后三位决定设备类型**（`006` = 开关），米家绑定巴法云账号后自动同步成"开关"设备，
小爱说"打开制冰机" → 云端下发 `on` → 本机按一下。

## 2. 你要做的（约 10 分钟）

### 2.1 注册巴法云、建主题

1. 打开 <https://cloud.bemfa.com> 注册（免费）
2. 进 **MQTT 控制台** → 新建主题，名字**必须以 006 结尾**，例如：
   ```
   bingji006
   ```
   （`bingji` 是设备名，米家里会显示成这个，之后可以在米家 App 里改名）
3. 记下控制台上的 **私钥**（一串字符，MQTT 的 ClientID 就是它）

### 2.2 设备端配置

串口（`pio device monitor -p COM6 -b 115200`）：

```
voice 你的巴法云私钥 bingji006
voice
```

预期输出：

```
已配置巴法云: 主题=bingji006

语音控制: 开启
私钥    : 已设置
主题    : bingji006
MQTT    : 已连接 bemfa.com:9501
收到指令: 0 条
```

### 2.3 米家绑定

1. 米家 App → **我的** → **其他平台设备** → **添加**
2. 找到 **「巴法」** → 登录同一个巴法云账号
3. 设备自动同步，出现一个"开关"（名字是 `bingji006`，可改名成"制冰机"）

### 2.4 试语音

对小爱说：

```
小爱同学，打开制冰机
小爱同学，关闭制冰机
小爱同学，制冰机开了吗
```

设备会按下按钮；串口日志会打印 `收到语音指令: on`。

## 2.5 ⚠️ MQTT 还是 TCP？先看你米家里能看到哪个

米家「其他平台设备 → 巴法」只同步**账号里对应协议类型**的设备云：

- 米家里只看到 **TCP 设备云** → 主题必须建成 **TCP**，设备端用 `voice tcp ...`
- 米家里有 **MQTT 设备云** → 主题建成 MQTT，设备端用 `voice mqtt ...`

两者固件都支持，命令里指定即可。

| 协议 | 服务器 | 备注 |
|---|---|---|
| TCP | `bemfa.com:8344` | 一行一条指令，60 秒内要发 `ping` 心跳 |
| MQTT | `bemfa.com:9501` | ClientID = 私钥，保持长连接 |

> 实测：这个账号米家里只有 TCP 设备云，所以走 TCP。

## 3. 固件里是怎么实现的

| 项 | 值 |
|---|---|
| Broker | `bemfa.com:9501`（明文 MQTT；也可以用 9503 TLS） |
| ClientID | 巴法云私钥 |
| 订阅主题 | `bingji006` |
| 收到 `on` | `applyAction(0)` = 确保开机（当前是关才按一下） |
| 收到 `off` | `applyAction(1)` = 确保关机 |
| 状态回传 | 每次动作后向 `bingji006/up` 发 `on`/`off`，让米家显示同步 |

串口命令：

| 命令 | 说明 |
|---|---|
| `voice tcp <私钥> <主题>` | 用 TCP 协议接入（米家只认 TCP 设备云时用） |
| `voice mqtt <私钥> <主题>` | 用 MQTT 协议接入 |
| `voice on` / `voice off` | 开关语音控制 |
| `voice` / `voice status` | 查看连接状态、收到多少条指令 |

## 4. 已知限制（重要）

1. **没有物理反馈**：制冰机按钮是"按一下切换"，固件只能记录"逻辑状态"。
   如果有人手动按了机器，或者断电重启过，逻辑状态会和实际不符 —— 说"打开"可能反而关掉。
   → 想彻底解决要加**电流检测**（看制冰机是否在耗电）或**光敏/门磁**，属于下一步硬件扩展。
2. **巴法云是第三方云**：米家「其他平台设备」这个入口过去有变动，如果哪天找不到"巴法"，
   这条路就断了。
3. **功耗**：MQTT 是长连接，比现在的 10 秒轮询更耗电一点。
   如果开着省电模式（`power on`），消息延迟可能到几百毫秒，功能正常。
   实测建议：先 `power off` 验证语音通不通，再开省电看延迟能不能接受。
4. **依赖公网**：语音控制必须设备联网。断网时小爱会提示"设备离线"。

## 5. 备选：自己接小爱开放平台

如果你有企业资质，可以走官方：

1. 小爱开放平台注册开发者 → 创建"轻应用/技能"
2. 配置语义（"打开制冰机" → intent `TurnOn`）+ Webhook
3. Webhook 指向你自己的服务器（`server/` 那个），服务器再通过 `/api/action` 下发

这条路的代码仓库里已经有基础：`server/server.js` 的 `/api/action` 就是现成的执行入口，
只要再加一个 `/xiaoai` 的语义解析端点即可。需要的话我可以写。
