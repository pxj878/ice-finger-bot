# USB 串口命令行（不需要 WiFi）

ESP32-C3 插上 USB 后就是一个串口设备。串口里直接敲命令，就能完成**校准舵机、建定时任务、对时、配 WiFi** 全部操作。
用途：WiFi 没配好、热点搜不到、或者临时改个角度不想开网页时。

## 1. 怎么用

```powershell
cd firmware
pio device monitor -p COM5 -b 115200
```

出现 `提示: USB 串口输入 help 可用命令行配置（不需要 WiFi）` 后直接输入命令回车。

也可以用任意串口助手（波特率 **115200**，数据 8 位，无校验，1 位停止位）。

## 2. 命令表

| 命令 | 说明 |
|---|---|
| `help` | 列出所有命令 |
| `status` | 固件版本、网络、时间、电源状态、舵机参数、任务数、内存 |
| `press` | 按一下（切换） |
| `on` / `off` | 设为开机 / 关机（按逻辑状态判断，already 就跳过） |
| `angle 45` | 舵机直接转到 45° 并保持（校准用，不自动回位） |
| `rest 25` | 设置抬起角度 |
| `down 75` | 设置压下角度 |
| `hold 600` | 设置按住毫秒（50–5000） |
| `task list` | 列出定时任务 |
| `task add 21:30 on 12345` | 加一条：21:30 开机，周一到周五 |
| `task add 23:00 off 67 once` | 加一条：23:00 关机，周六周日，单次 |
| `task del 2` | 删除第 2 条 |
| `task clear` | 清空全部任务 |
| `sched on` / `sched off` | 定时总开关 |
| `time` | 查看当前时间 |
| `time 2026-10-18 21:00:00` | 手动设置时间（没联网时用这个对时） |
| `wifi MyHome 12345678` | 设置 WiFi，2 秒后自动重启 |
| `scan` | 扫描附近 WiFi（看信号强度） |
| `logs` | 打印最近 24 条运行日志 |
| `reset` | 恢复出厂（清空 WiFi + 任务） |
| `reboot` | 重启 |

## 3. 几个细节

- **星期**：`1234567` 表示周一到周日；**不写 = 每天**。
- **动作**：`on`=开机、`off`=关机、`toggle`=无条件按一下。
- **任务上限** 16 条，超了会提示「任务已满(16)」。
- **时间**：C3 没有电池 RTC，断电就丢；联网会自动 NTP 对时，没联网时每次上电用 `time ...` 设一次，
  否则定时任务不会触发（`status` 里时间显示异常就是这个原因）。
- **持久化**：所有配置写进 Flash（NVS），重启/断电都不丢。
