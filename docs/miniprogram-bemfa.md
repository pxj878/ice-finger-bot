# 小程序：巴法云直连模式（远程控制，零服务器零域名）

> 用途：手机在外面也能开关制冰机、改云端定时任务。
> 依赖：巴法云账号（免费）+ 小程序后台加一个域名白名单。

## 1. 原理

```
微信小程序 --HTTPS--> apis.bemfa.com --TCP--> ESP32
```

巴法的 API 域名本身就是 HTTPS，所以**不需要买域名、不需要服务器、不需要备案**去搭中转。

## 2. 唯一的前置条件（只有你能做）

微信公众平台 → 开发管理 → 开发设置 → 服务器域名 → **request 合法域名** 添加：

```
https://apis.bemfa.com
```

- 保存成功 → 这条路可行
- 提示"域名未备案/不合法" → 这条路走不通，改用 `docs/server.md`（自建服务器）或 `docs/cloud.md`（微信云开发）

## 3. 小程序里怎么切

1. 打开小程序 → **设置** 页 → 顶部的「连接方式」
2. 选「**巴法云（远程）**」
3. 填两个值：
   - **巴法云私钥**（32 位，控制台首页）
   - **主题**（`bingji006`）
4. 点「保存并测试」→ 提示"已连接，设备在线"就成功了

之后控制页的开关、定时页的任务都会走巴法云。

## 4. 两种模式对比

| | 局域网直连 | 巴法云（远程） |
|---|---|---|
| 需要 | 手机同一 WiFi | 只需联网 |
| 开关 | ✅ | ✅ |
| 状态 | ✅ 完整（角度/信号/内存） | ⚠️ 只有开关 + 在线 |
| 定时任务 | ✅ 本地，离线也执行 | ⚠️ 云端，设备离线会漏 |
| 舵机校准 | ✅ | ❌ |
| 改 WiFi / 重启 | ✅ | ❌ |

## 5. 云端定时的行为

- 任务存在**巴法云**，到点由云端向主题推 `on`/`off`
- **不支持**"切换"（只支持开/关），也不支持"单次"
- 设备离线时**会漏执行**（不补发）
- 保存时会**先清空云端所有任务再重建**（任务数少，够用）

> 设备本地也有一套定时（更可靠）。建议二选一，不要两边都设，否则会重复按。

## 6. 安全

- 私钥只存在**手机本地 Storage**，不写死在代码里
- **不要公开发布**这个功能：用体验版 + 体验成员（家人）即可
- 泄露了就换：巴法控制台重置私钥 → 设备串口 `voice tcp <新私钥> bingji006` → 小程序重填

跑法：

```powershell

```

## 8. 代码结构

| 文件 | 作用 |
|---|---|
| `utils/bemfa.js` | 巴法 API 封装（状态/开关/定时/星期转换） |
| `utils/api.js` | 连接方式切换：`lan` 走设备 HTTP，`bemfa` 走巴法 |
| `pages/settings` | 连接方式选择 + 私钥/主题输入 |
| `pages/index`、`pages/schedule` | 页面不用改，走同一套接口，云端模式自动隐藏不支持的项 |
